# Durgadas Pagare — Portfolio Website

A responsive, white-and-blue portfolio built with HTML, CSS and vanilla JavaScript.

## Included
- Responsive navigation with mobile menu
- Hero section with your portrait and stats (7+, 10+, 4+)
- About section and updated journey timeline
- Skills cards with category filters, including MongoDB
- Projects: MovieFlix, Artistic Fusion, Music Streaming Website
- Achievements and resume area
- Contact form validation demo
- Scroll reveal animations and active navigation
- No dark/light theme toggle

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or use VS Code's Live Server extension.
3. Replace sample project URLs with each project's real demo/repository URL.
4. Replace `your-email@example.com` with your actual email.
5. Add your resume PDF as `assets/resume.pdf`.
6. Add your LinkedIn profile URL where marked.
7. To receive contact form messages, connect a backend or an email service; the included form only validates in the browser.

## Files
- `index.html` — page content
- `style.css` — responsive styling
- `script.js` — filters, mobile menu, scroll reveal and form feedback
- `assets/profile.jpg` — profile photo
